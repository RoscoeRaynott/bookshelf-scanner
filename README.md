# Multi-Bookshelf Scanner & Master Cataloger

An intelligent computer vision and cataloging app for bookstores and home libraries.

## Features
- **Multi-Image Upload**: Upload multiple bookshelf photos from gallery/camera.
- **Location Tracking**: Tracks each book by `Image #`, `Shelf #`, and `Book #`.
- **Rotated Bounding Boxes**: Detects and highlights upright, slanted, and face-out books.
- **Story Continuity**: Identifies Sequential Series (Trilogies/Septalogies), Recurring Protagonists (Reacher, Cross, Holmes, Allon), and Standalone novels.
- **Sensual Romance Filter**: Option to filter out explicit romance/sensual content.
- **TV / Screen Adaptations**: Flags verified TV adaptations (Prime, Netflix, BBC, etc.).
- **Sales & Popularity Ordering**: Sorted by bestselling ranks and author popularity.
